# 🎮 3D 坦克大战 · Tank Battle 3D

一款基于 **Three.js** 的 3D 坦克对战游戏，所有代码都写在一个 HTML 文件中，**无需安装、无需构建，双击即玩**。  
支持波次模式、冒险模式、多人联机（P2P）和单浏览器分屏模式，并针对高帧率进行了大量优化。

## ✨ 核心特性

- 🎯 **多种游戏模式**
  - **波次模式**：固定地图，一波波敌人来袭，消灭全部敌人进入下一波。
  - **冒险模式**：无限世界，地形动态生成，敌人和障碍物围绕玩家游走生成。
  - **多人模式**：通过房间码与好友联机，在同一世界中互相伤害（最多 8 人）。
  - **分屏模式**：单浏览器多实例，所有实例自动加入同一房间，从左到右排列，适合大屏触屏。

- 🗺️ **柏林噪声地形**  
  使用 Perlin Noise 生成自然起伏的地形，冒险/多人模式每次随机种子，波次模式使用固定种子。

- 💥 **可摧毁障碍物**  
  障碍物可被炮弹和地雷摧毁，并且坦克可以爬上障碍物顶部获得更好的射击视野。

- 🤖 **智能敌军**  
  敌军会锁定最近的玩家，围绕玩家游走生成，距离过远自动销毁。

- 🔫 **战斗系统**
  - 自动锁头（可在冒险/多人模式中自由旋转炮塔）
  - 高射速、秒杀级伤害
  - 地雷（E 键 / 💣 按钮）
  - 大招清图（Q 键 / ⚡ 按钮，3 秒冷却）
  - 第一人称 / 第三人称切换（V 键）

- 🖥️ **高帧率优化**  
  关闭阴影、降低像素比、共享几何体、地形高度缓存、粒子池、帧率上限控制等，帧率提升约 100%。

- 📱 **触屏支持**  
  移动端自动显示虚拟方向键和功能按钮，支持大屏多点触控。

- 🔇 **静音按钮**  
  开始页面提供静音切换，状态保存在 localStorage，分屏实例自动同步。

## 🕹️ 游戏模式详解

### 波次模式
- 固定 600×600 地图，柏林噪声地形。
- 一波波敌人刷新，数量随波次增加。
- 消灭当前波次所有敌人后进入下一波。

### 冒险模式
- 地图以玩家为中心动态刷新（地形尺寸 900）。
- 敌人和障碍物在玩家周围 60~180 范围内游走生成。
- 每个玩家周围的敌人数量有独立上限。
- 距离玩家超过 180 的敌人和障碍物自动销毁。

### 多人模式
- 基于 **PeerJS** 的 P2P 联机，房主创建房间生成 6 位房间码。
- 其他玩家输入房间码加入，最多支持 8 人。
- 共享地形种子，所有玩家在同一世界中。
- 玩家之间可以互相伤害，击杀得 500 分。

### 分屏模式
- 在同一个浏览器页面中同时运行 2 / 4 / 6 / 8 个游戏实例。
- 所有实例自动加入同一个房间，布局从左到右排列。
- 创建房间和加入房间失败时自动重试（最多 5 次）。
- 4 屏及以上自动启用低画质模式。

## 🚀 如何运行

### 本地运行
1. 下载 `index.html`（或复制完整代码保存为 `.html` 文件）。
2. 用现代浏览器（Chrome / Edge / Firefox / Safari）直接打开。
3. 开始游戏！

> 多人模式需要网络访问 `unpkg.com` 获取 Three.js 和 PeerJS。

### 部署到 GitHub Pages
1. 将 HTML 文件推送到 GitHub 仓库。
2. 在仓库 **Settings → Pages** 中选择分支和目录。
3. 访问生成的链接即可在线游玩。

## 🛠️ 技术栈

- **Three.js** `r160` — 3D 渲染引擎
- **PeerJS** `1.5.2` — WebRTC P2P 联机
- **Web Audio API** — 程序化音效（无外部音频文件）
- **Perlin Noise** — 自实现地形生成
- **localStorage** — 静音状态和分屏房间码共享
- **Canvas 2D** — 动态生成地面纹理

## 🔧 自定义配置

在代码开头的“全局常量”区域可以调整游戏参数：

| 常量 | 说明 | 默认值 |
|------|------|--------|
| `PLAYER_MAX_HP` | 玩家血量 | `10000` |
| `ENEMY_MAX_HP` | 敌人血量 | `10000` |
| `PLAYER_DAMAGE` | 玩家伤害 | `40 * 9e13` |
| `ENEMY_DAMAGE` | 敌人伤害 | `1` |
| `PLAYER_SPEED` | 玩家移速 | `15 * 4` |
| `ADV_SPAWN_RADIUS` | 冒险模式生成半径 | `180` |
| `ADV_MAX_ENEMIES` | 冒险模式敌人上限 | `80` |
| `MAX_FPS` | 最大帧率 | `90` |
| `PIXEL_RATIO_MAX` | 像素比上限 | `1.1` |
